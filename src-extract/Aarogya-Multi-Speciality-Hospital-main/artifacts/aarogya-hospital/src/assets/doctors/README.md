# Doctor photos

Put one photo per doctor in this folder, named exactly:

- `venkatesh.jpg` for Dr. U. Venkatesh
- `vandana.jpg` for Dr. K. N. Vandana

`.jpg`, `.jpeg`, `.png` and `.webp` all work. A portrait (taller than wide) with the face in the
upper third looks best. The site picks them up on its own; until a photo is here, the card shows
the department illustration instead.
